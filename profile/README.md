## About

XAUE builds open-source tools at the intersection of **AI** and **Web3**. We explore how AI agents, large language models, and decentralized protocols work together — and we build the open infrastructure that connects AI assistants to real-time on-chain gold data.

## 🚀 Featured Projects

| Project | Description |
|---------|-------------|
| **[xaue-mcp-server](https://github.com/xauecom/xaue-mcp-server)** | A Model Context Protocol (MCP) server that lets AI assistants read real-time XAUE on-chain metrics — supply, NAV, APY, reserves — directly from Ethereum. |
| **[skills](https://github.com/xauecom/skills)** | A collection of reusable [Agent Skills](https://agentskills.io/specification) for AI coding agents, including on-chain gold trading. |
